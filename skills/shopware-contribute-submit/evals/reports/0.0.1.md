# Evaluation report: shopware-contribute-submit 0.0.1

## Changes

- First release, for review in
  [#1984](https://github.com/shopware/shopware-cli/issues/1984).

## Method

- **Scenarios:** every scenario in [`../scenarios.json`](../scenarios.json),
  5 scenarios, 13 criteria.
- **Runs:** one run per condition, Claude Opus 5.5, in a clone of
  shopware/shopware-cli with read-only GitHub access. **Without:** no
  contributor skills. **With:** all three contributor skills installed; the
  agent chose which to load from their descriptions.
- **Judge:** a separate Claude Opus 5.5 agent scored each criterion pass, fail
  or n/a for both runs against the same standard. It saw which run had the
  skills, so the scoring is not blind.

## Known issues for the next version

- `bug-no-repro/repro`: borderline; asking for the exact command could count as
  asking for reproduction steps.
- `review-changes-requested/read-comments` and `read-checks`: the prompt names
  no pull request, so both runs were judged on their stated plan. Add a real
  pull request to the prompt.

## Limitations

- One run per condition with one model: no variance estimate.
- An LLM judge, not blind, scored the runs; borderline calls are listed above.
- Passing scenarios is not proof that the skill works for real contributors.
